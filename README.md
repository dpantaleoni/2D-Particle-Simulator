2D-Particle-Sim is a 2D N-body gravitational simulation that models particles interacting via Newtonian gravity. It includes five implementations: a C version using pthreads, a Python version using multiprocessing + shared memory + NumPy, a C++ version with real-time visualization via raylib and optional GPU acceleration, a distributed MPI version using mpi4py for multi-node parallelism, and a Spark version using PySpark RDDs for distributed force computation. Each implementation supports a configurable number of particles, runs for a fixed number of timesteps, and reports total simulation time for performance comparison across languages and architectures.
